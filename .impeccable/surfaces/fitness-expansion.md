# Fitness extension direction

Mode: Operate. Local extension of RIVL's approved white/ink/coral native interface. Preserve logo 01, compact type, flat list separators, shared fields/buttons and native switch. No new visual world or generated assets.

Gear: You → Gear opens a private owner-scoped mileage list with one Add gear action. Form uses shared compact heading and fields for name/type/starting kilometres/default. Historical assignments survive retirement. Real data or honest empty states only.

Automatic start: Settings → Automatic recording. Concise foreground-only explanation, switch, labeled Sport selection, then platform-specific consent and review/battery limitations. No redundant disable button. Off by default; do not imply closed-app detection or automatic publication.

QUALITY BAR: The important control and sport choice must be visible before detailed limitations; native targets, readable type and clear validation; no demo athlete or invented mileage. Review scope is iPhone light appearance, empty gear and add form, and automation settings. Populated gear, dark/large text and Android remain outside this captured acceptance scope.
