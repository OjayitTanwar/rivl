# Strava UI references

Ten public source images collected on 13 October 2026 for the requested RIVL redesign. `reference-board.jpg` is a contact sheet; the original full-size files remain beside it. No reference images ship inside the app.

`home`, `community`, `routes`, `activity-strength`, and `record-sport` are marketing screenshots supplied by Strava on https://apps.apple.com/us/app/strava-run-bike-walk/id426826309. The image names describe their reference roles; the manifests retain the precise origin URLs.

`record-map`, `record-stats`, `record-paused`, `save-activity`, and `record-legacy` are screenshots from https://support.strava.com/en-us/articles/15402137-how-do-i-record-an-activity-on-strava. The legacy screenshot is explicitly older and is not authority for the current navigation.

This collection covers publicly visible examples, not every authenticated or subscription screen. Sources: `sources.json` and `recording-sources.json`.
