# What remains

Updated 16 October 2026. Implementation, hosted deployment and device validation are separate milestones.

## Community GPS: first priority

Mapped-path support and bounded unmapped centerline proposals are deployed. Private proposals require five independent owners across three days, privacy revalidation and explicit reviewer approval. Public geometry disappears when current support fails, expires or is disputed. Discovery does not establish legal access, physical separation or safety, and is not used as a routing edge.

Remaining: genuine multi-athlete outdoor validation, operator-assigned reviewers, field calibration across parallel trails/junctions/bridges, and observed queue/provider performance. No fabricated production journeys were seeded.

## Implemented in this batch

- Public shared routes with publish, browse, save, report and attribution.
- Clubs with organizer roles, events and capacity-safe RSVP.
- Explicit foreground live sharing with selected accepted friends and server expiry.
- Staff moderation console, separate GPS reviewer role and audited decisions.
- Training pace/heart-rate/power/repetition targets, explicit adaptive suggestions and original CC0 starter plans.
- Health HRV trends, blood pressure, cycle and medication logs; nutrition micronutrients, camera barcodes and reviewed photo/voice drafts.
- Fresh versioned topology for offline rerouting; expired or legacy downloads remain display-only.

These features have source and database tests. Populated application flows and physical hardware checks remain necessary.

## Launch and external setup

- Custom SMTP, ordinary external-mail confirmation/recovery/deletion OTP tests; registered Apple/Google OAuth credentials and native callback verification. Providers remain disabled until configured.
- Activate encrypted backup destination/recipient and hosted workflow, then prove restore into a disposable project. Current tooling is dormant.
- Appoint moderators/reviewers and a real support channel; run the response process.
- Measure pilot database/Storage/egress/worker costs and response times. No supported-athlete number or free-forever guarantee has been established.
- Physical GPS/locked-screen recovery, Health/Watch/BLE, microphone/camera, keyboard/accessibility and Android checks; real hosted segment/Local Legend integrity flows.
- Licensed full offline basemaps, richer verified terrain and operated background safety delivery remain outside the current foreground/path-download feature.
- Store distribution requires the appropriate Apple/Google accounts and setup. A signed phone install and GitHub source are separate from TestFlight/App Store release.
